## FAQ

**Does it work with OpenMW saves?**  
Yes — both OpenMW and vanilla Morrowind save formats are supported.

**Where can I find item IDs?**  
The editor has a built-in searchable item database with all vanilla IDs. Mod item IDs require the mod to be loaded.
